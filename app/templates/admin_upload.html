Allocations

Bikes already delivered (off the orders sheet) — used to reduce the forecast off the front of the queue. Cumulative: each upload adds new rows, deduped by order number. Uploading a new plan wipes allocations to start a fresh period. Accepts either a single-period file (filename pattern Allocations DD.MM.YY am|pm.xlsx) or a master workbook whose sheets are named per period (DD.MM.YY am|pm) — the system ingests every dated sheet chronologically and dedups across them. Older-dated single-period files are rejected.

Filename pattern: Allocations DD.MM.YY (am|pm).xlsx

Accounting month

The 12-month availability window starts from this month, and allocations are consumed from the forecast starting here. It follows the dates in the allocation file automatically — so an allocation master for June keeps the figures on June even after the calendar rolls into July. Pin it manually only to force a different month.
